# design-system-type

Create a complete typography system.

## Steps

1. **Scale** — Build a modular type scale using `design-system-typography-scale` skill.
2. **Hierarchy** — Define hierarchy levels using `interaction-visual-hierarchy` skill.
3. **Responsive** — Adapt scale across breakpoints using `interaction-responsive-design` skill.
4. **Spacing** — Define text spacing relationships using `design-system-spacing` skill.
5. **Grid alignment** — Align to baseline grid using `interaction-layout-grid` skill.
6. **Document** — Output complete type system with usage rules.

## Output

Typography system with scale, styles, responsive behavior, spacing, grid alignment, and usage guidelines.
Consider following up with `interaction-design-screen` to apply the type system.

## Build

Use the `figma-use` skill to materialize this as a new frame on the current page in the active Figma file, named `design-system-type — [input]`. Lay it out using the layout, typography, color, and spacing conventions established above. Build incrementally and verify the result with a screenshot before finishing.
