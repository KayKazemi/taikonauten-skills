# strategy-strategize

Develop a comprehensive UX strategy.

## Steps

1. **Vision** — Articulate the north-star using `strategy-north-star-vision` skill.
2. **Landscape** — Analyze competitors using `strategy-competitive-analysis` skill.
3. **Map** — Create experience map using `research-experience-map` skill.
4. **Principles** — Define guiding principles using `strategy-design-principles` skill.
5. **Opportunities** — Evaluate and prioritize using `strategy-opportunity-framework` skill.
6. **Metrics** — Define success measures using `strategy-metrics-definition` skill.
7. **Brief** — Consolidate into a design brief using `workflow-design-brief` skill.

## Output

Strategy document with vision, competitive landscape, experience map, principles, prioritized opportunities, metrics, and design brief.
Consider following up with `testing-benchmark` or `strategy-frame-problem`.

## Build

Use the `figma-use` skill to materialize this as a new frame on the current page in the active Figma file, named `strategy-strategize — [input]`. Lay it out as a polished one-page document: an eyebrow label, bold headline, and meta line at the top; numbered sections with clear typographic hierarchy; tables for structured or comparative data; and colored status badges or callout boxes to highlight key points, severity, or priority where relevant. Build incrementally and verify the result with a screenshot before finishing.
