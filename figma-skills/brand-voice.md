# Brand Voice

Define how a brand speaks so that every piece of communication — from error messages to ad headlines — sounds like it comes from the same place.

## Context

You are a brand language strategist helping define the voice for $ARGUMENTS. If existing communication samples are provided, analyse them first for patterns.

## Domain Context

- Voice is consistent (who the brand is); tone shifts by context (how it speaks in different situations).
- Nielsen Norman Group: A distinct voice builds trust and memorability; an inconsistent one erodes both.
- Good voice guidelines give writers permission, not a straitjacket.

## Building the Voice Framework

1. **Brand foundation**: Before defining voice, confirm or define the brand's personality, values, and audience using the `brand-strategy` skill — voice should express a foundation that already exists, not invent one.
2. **Voice pillars**: Define 3–4 core characteristics (e.g., "Direct", "Warm", "Curious"). For each: a one-line definition, 2–3 writing examples, and what it is not.
3. **Tone spectrum**: Map how the voice shifts across contexts (e.g., formal → informal, serious → playful) for key contexts: error states, marketing, onboarding, support, social.
4. **Vocabulary**: Define words and phrases the brand uses, words and phrases to avoid, and how much jargon is appropriate for which audience.
5. **Messaging hierarchy**: Write the brand tagline or signature line, an elevator pitch (1 sentence, 1 paragraph, 1 page), and key messages by audience segment.
6. **Writing principles**: Define sentence length and rhythm preferences, active vs. passive voice, and punctuation/capitalisation quirks.
7. **Writing examples**: Produce 5 real-world writing samples that demonstrate the voice in practice — a homepage headline, an error message, a social post, an email subject line, and a push notification.

## Instructions

Work through each section of the voice framework for $ARGUMENTS. For each voice pillar, write three before/after examples that demonstrate the difference between on-brand and off-brand writing.

## Output

Brand voice guide with pillars (with before/after examples), tone map, messaging hierarchy, vocabulary list, and the 5 annotated writing examples.

Consider following up with `workflow-design-rationale` to document the strategic reasoning behind voice decisions.
